# Amazon Homepage Clone

A frontend recreation of the Amazon homepage built using **HTML and CSS**. This project was created to practice webpage structure, responsive layout concepts, navigation components, Flexbox, styling, and frontend design.

## 🚀 Live Demo

[View Live Demo](https://amazon-homepage-clone-ivory.vercel.app/)

## 📌 Features

* Amazon-style navigation bar
* Amazon logo section
* Delivery location section
* Search bar with category selector
* Sign-in and account section
* Returns & Orders section
* Shopping cart section
* Secondary navigation panel
* Hero/banner section
* Promotional message
* Product/category cards
* Multiple shopping categories
* Footer with multiple navigation columns
* "Back to top" footer section
* Amazon-inspired dark navigation and footer styling

## 🛠️ Technologies Used

* **HTML5** — Page structure and semantic organization
* **CSS3** — Layout, styling, Flexbox, spacing, colors, and backgrounds
* **Font Awesome** — Icons used throughout the navigation and interface

## 🎯 Project Objective

The main objective of this project was to recreate the visual structure of an e-commerce homepage and strengthen my understanding of frontend development.

Through this project, I practiced:

* HTML page structuring
* CSS Flexbox
* Navigation bar design
* Search bar implementation
* Hero sections
* Card-based layouts
* Background images
* Footer design
* CSS spacing and positioning
* Using external icons with Font Awesome
